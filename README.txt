This version is a complete connected FRONTEND prototype. Profiles and demo account state use browser localStorage, so data is stored only on the device/browser. It is NOT secure authentication and should not be used for real passwords or private data.

For a production version, the next phase is a real backend for authentication, database, image storage, uploads, comments, likes and follows.
